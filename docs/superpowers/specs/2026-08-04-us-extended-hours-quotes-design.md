# 美股盘前盘后行情设计说明

## 目标

在不改变现有正式持仓、累计收益和盈亏日历计算口径的前提下，为美股持仓增加盘前、盘后行情及对应的预估盈亏，帮助用户在美股常规交易时段之外快速判断持仓变化。

本次只扩展美股。A 股和港股继续使用现有行情与交易时段逻辑。

## 核心口径

### 行情基准

- 盘前涨跌：盘前价格相对上一交易日正式收盘价的变化。
- 盘后涨跌：盘后价格相对当日正式收盘价的变化。
- 常规交易时段：继续展示现有实时价格、当日盈亏和当日涨跌。
- 休市且没有有效扩展时段报价：展示最近正式收盘价，不伪造盘前或盘后数据。

### 盈亏口径

- 盘前预估盈亏 = `(盘前价格 - 上一交易日正式收盘价) × 持仓数量`。
- 盘后预估盈亏 = `(盘后价格 - 当日正式收盘价) × 持仓数量`。
- 单只股票的扩展时段预估盈亏保留美元口径。
- 美股持仓标题区域汇总所有有效扩展时段预估盈亏，并按现有汇率换算人民币作为辅助信息。
- 正式总资产、今日盈亏、累计收益、资产走势图和盈亏日历继续使用正式行情与现有会计口径。
- 扩展时段数据不得写入正式历史快照，避免第二天重复计算或污染月度、年度收益。

## 数据源

### 主数据

- Finnhub 继续负责现有美股正式报价。
- Finnhub `market-status` 用于识别 `pre-market`、`regular`、`post-market` 和休市状态。

### 扩展时段数据

- 使用 Yahoo Finance 公共行情接口批量读取美股的 `preMarketPrice`、`preMarketChange`、`preMarketChangePercent`、`postMarketPrice`、`postMarketChange`、`postMarketChangePercent` 及时间戳。
- 一次请求批量查询全部美股代码，避免逐只请求。
- Yahoo Finance 属于免费公共接口，不保证商业级稳定性，因此必须有明确降级逻辑。

### 降级规则

1. Yahoo Finance 返回当前扩展时段有效报价时，展示价格、涨跌额、涨跌幅和预估盈亏。
2. 当前时段报价缺失，但最近一次缓存数据仍在有效期内时，展示缓存并标记更新时间。
3. 数据超时或接口失败时，显示“暂无盘前行情”或“暂无盘后行情”，不得用正式价格冒充扩展时段价格。
4. Finnhub 市场状态不可用时，根据美东时间推断展示标签，同时标记为“时段待确认”；不影响正式行情刷新。

## 刷新机制

- 正式行情继续遵循现有刷新频率。
- 扩展时段行情最多每 60 秒请求一次，即使页面设置为 15 秒刷新也复用 60 秒缓存。
- 用户点击手动刷新时，可立即请求一次扩展时段行情。
- 扩展时段活跃期间，超过 15 分钟未更新的数据标记为“已延迟”。
- 浏览器页面不可见时不额外增加请求频率；恢复可见后按缓存状态决定是否刷新。
- 本地和 Render 线上服务各自刷新，不依赖浏览器一直打开。

## 服务端数据结构

每只美股持仓在 API 响应中增加以下只读字段：

```json
{
  "extendedSession": "pre-market",
  "extendedPrice": 123.45,
  "extendedChange": 1.23,
  "extendedChangePercent": 1.01,
  "extendedEstimatedPnl": 6.15,
  "extendedUpdatedAt": "2026-08-04T11:30:00.000Z",
  "extendedStatus": "live"
}
```

字段规则：

- `extendedSession`：`pre-market`、`post-market` 或 `null`。
- `extendedStatus`：`live`、`cached`、`delayed`、`unavailable`。
- 没有有效扩展报价时，数值字段为 `null`，前端不得显示为零。
- 这些字段只参与展示，不更新持仓成本、正式现价和历史快照。

服务端维护一份按股票代码索引的短期扩展行情缓存。缓存不作为交易记录或资产历史的事实来源。

## 页面设计

### 美股持仓表

美股表格增加独立的“盘前/盘后”列，不将信息挤入“现价”或“当日盈亏”列。

每行展示：

- 第一行：时段标签与扩展价格，例如“盘前 $123.45”。
- 第二行：涨跌额与涨跌幅，例如“+$1.23 · +1.01%”。
- 第三行或悬浮信息：该持仓扩展时段预估盈亏与更新时间。
- 上涨使用现有盈利色，下跌使用现有亏损色，无数据使用中性色。

常规交易时段：

- 该列显示“交易中”。
- 正式现价和当日盈亏继续实时更新。
- 若盘前数据仍在缓存中，不继续作为当前值突出展示。

### 美股持仓汇总

在“美股持仓”标题附近增加紧凑摘要：

- 当前状态：盘前、交易中、盘后或休市。
- 扩展时段预估盈亏总额。
- 最近更新时间。

该摘要明确标注“预估”，视觉层级低于正式累计收益。

### 移动端

- 美股持仓保持横向滚动，冻结名称列。
- “盘前/盘后”列保持独立，不与成本、现价、总盈亏、当日盈亏合并。
- 汇总信息在标题下方单独换行，避免压缩股票名称和操作按钮。
- iPhone 窄屏下确保价格、百分比和状态标签不重叠。

### 深浅模式

- 深色和浅色模式均使用现有语义色变量。
- 扩展时段标签不使用高饱和大面积底色，只以小型状态标记和数字颜色区分。
- 延迟和不可用状态必须有足够文字对比度，不能只依赖颜色。

## 同步与部署

- 本地与线上使用同一套前后端代码和字段定义。
- Render 环境继续读取现有 `FINNHUB_API_KEY`，无需新增付费密钥。
- Yahoo Finance 扩展行情无需新增用户密钥。
- 部署后先验证 Render 版本已更新，再执行一次本地到线上的持仓状态同步，避免在线临时数据库回退。
- 同步过程不得把扩展行情缓存当作长期资产数据覆盖线上正式持仓。

## 异常与边界

- 美股节假日：市场状态为休市，扩展时段列显示“休市”或“暂无扩展行情”。
- 夏令时：优先使用 Finnhub 市场状态，不在前端硬编码固定北京时间。
- 停牌股票：保留最近正式报价，扩展时段显示不可用。
- 零持仓股票：不参与扩展时段预估盈亏汇总。
- Yahoo 返回零值、缺少时间戳或时间戳不属于当前交易日时，视为无效数据。
- 网络失败不得阻断正式行情刷新，也不得清空已有正式报价。

## 验收标准

1. 美股盘前时段，每只有效持仓显示盘前价格、相对前收的涨跌额和涨跌幅。
2. 美股盘后时段，每只有效持仓显示盘后价格、相对正式收盘的涨跌额和涨跌幅。
3. 汇总预估盈亏等于有效单只持仓扩展时段预估盈亏之和。
4. 常规交易时段仍使用正式行情更新今日盈亏，扩展列显示“交易中”。
5. 扩展行情不可用时有明确状态，不显示伪造的 `0.00`。
6. 正式总资产、累计收益、盈亏日历和历史快照不因扩展行情变化。
7. 本地和线上页面字段、样式和数据口径一致。
8. 桌面端、iPhone 窄屏、深色模式和浅色模式均无文字重叠或列错位。
9. 扩展行情请求频率不高于每 60 秒一次，手动刷新除外。
10. Yahoo Finance 请求失败时，Finnhub 正式行情仍可正常刷新。
